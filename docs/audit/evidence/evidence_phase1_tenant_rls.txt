3. Database Role Ownership Bypass
File: deploy_vps_ubuntu.sh (line 66) & deploy_lightsail_jacobs.sh (line 61)
Code: ALTER DATABASE ${DB_NAME} OWNER TO ${DB_USER};
PostgreSQL Specification: Table owners bypass Row Level Security by default unless 'ALTER TABLE ... FORCE ROW LEVEL SECURITY' is explicitly set on every table. If tables are created without FORCE, runtime user bypasses RLS policies entirely.
